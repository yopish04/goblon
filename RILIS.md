Versi 0.2.0: mode Sablon (separasi warna), ingat pengaturan + preset sendiri + proyek, Undo/Redo dan tombol cepat, penghapus (kuas), export banyak (batch), gang sheet, putar/cermin, margin export, pustaka tekstur, pola dither & interlock, Perbesar AI, Lindungi teks, tampilan baru, update otomatis.

- Baru: halaman awal untuk memilih DTF atau Sablon (bisa diingat), dan saklar DTF | Sablon di bar atas.
- Sablon: separasi warna otomatis jadi film per tinta (underbase putih, warna, highlight putih), metode Simulasi / Index / Spot, tinta bisa diganti sesuai stok, simulasi hasil cetak dengan angka kemiripan warna, export film dengan tanda registrasi dan urutan cetak.
- Sablon: set tinta siap pakai sesuai warna kaos (6 warna dasar + abu / hitam, abu dicetak dulu, hemat, gelap / api / vintage) dan "Tinta saya"; tinta yang hampir tidak terpakai otomatis dibuang (hemat screen); gaya titik Satu sudut / Roset / Interlock; expand warna; boost warna dan boost per tinta; underbase bisa dipindah dalam urutan cetak.

- Pengaturan terakhir otomatis diingat; "Preset saya"; simpan/buka proyek (.szproj).
- Ctrl Z / Ctrl Y, Ctrl O, Ctrl Shift O, Ctrl S, Ctrl E.
- Penghapus dan "Kembalikan" dengan ukuran kuas ([ dan ]).
- Export banyak gambar sekaligus: lebar tetap atau muat dalam kotak (mis. 30 × 40 cm).
- Gang sheet: banyak desain dalam satu lembar film, susunan otomatis paling hemat; desain bisa digeser dengan mouse, dan gambar mentah (JPG, PNG berlatar) langsung diproses dengan pengaturan tab Desain.
- Putar 90° / cermin, margin transparan di sekeliling PNG.
- Kaos dipilih otomatis sesuai warna latar desain, dengan tombol Batalkan bila kaos berganti.
- Pustaka tekstur sendiri (tambah banyak sekaligus, tersimpan) dan tumpuk sampai 3 tekstur.
- Pola baru: Halftone interlock (paling rapi), Dither Bayer, Dither difusi.
- Perbesar AI: gambar kecil / blur diperbesar 4× dan ditajamkan langsung di komputer (tanpa internet), juga opsi di Export banyak. Hasilnya disimpan di cache aplikasi (bukan file baru setiap klik) dan bisa di-Undo; file baru dibuat saat proyek disimpan. Otomatis memakai kartu grafis (AMD / NVIDIA / Intel) bila ada dan lolos tes, kalau tidak memakai prosesor.
- Lindungi teks (opsi di tab Halftone): tulisan dicetak padat dengan warna aslinya, atau "Titik halus" (tetap halftone dengan titik lebih rapat), bagian lain tetap halftone; Kuas teks untuk koreksi, area teks diberi arsir biru di pratinjau.
- Menu ⚙ Pengaturan: tema Terang / Gelap / Ikuti Windows (pratinjau tetap abu-abu netral), bahasa, kehalusan dan perangkat AI.
- Bahasa: English (bawaan) atau Bahasa Indonesia.
- Tampilan baru yang lebih ringkas: bar atas + panel bertab dengan ikon, muat di layar 1366 × 768.
- Mulai versi ini aplikasi memberi tahu bila ada versi baru; klik "Update sekarang".
